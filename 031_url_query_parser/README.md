# 🦀 URL Query String Parser & Encoder (`031_url_query_parser`)

**Difficulty:** 🟢 Simple  
**Category:** Web & Networking  

---

## 📖 Overview

Parses and serializes URL query parameters with percent-encoding and decoding.

---

## 🎯 Key Rust Concepts Demonstrated

- **Percent Encoding (%20, +)**
- **URL Structure Splitting**
- **Multi-Value Query Maps**
- **RFC 3986 Compliance**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
