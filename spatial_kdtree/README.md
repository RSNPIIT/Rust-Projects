# 🦀 Multidimensional Spatial K-d Tree (`091_spatial_kdtree`)

**Difficulty:** 🔴 Advanced  
**Category:** Computational Geometry & Trees  

---

## 📖 Overview

2D/3D K-d tree space-partitioning data structure for fast nearest-neighbor search and range queries.

---

## 🎯 Key Rust Concepts Demonstrated

- **Space Partitioning**
- **Alternating Dimension Splitting**
- **Nearest Neighbor Pruning**
- **Computational Geometry**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
