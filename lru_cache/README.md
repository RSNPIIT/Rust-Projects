# 🦀 LRU Cache (Least Recently Used) (`038_lru_cache`)

**Difficulty:** 🟡 Intermediate  
**Category:** Data Structures & Caching  

---

## 📖 Overview

O(1) capacity-bounded Least Recently Used cache implemented with a HashMap and index-linked doubly list.

---

## 🎯 Key Rust Concepts Demonstrated

- **Doubly-Linked List Pointer Simulation**
- **HashMap Lookup O(1)**
- **Capacity Eviction**
- **Interior References**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
