# 🦀 Single-Decree Paxos Consensus Simulator (`087_paxos_consensus_simulator`)

**Difficulty:** 🔴 Advanced  
**Category:** Distributed Systems & Consensus  

---

## 📖 Overview

Simulation of classical single-decree Paxos: Prepare/Promise phase (Phase 1) and Propose/Accept phase (Phase 2).

---

## 🎯 Key Rust Concepts Demonstrated

- **Paxos Consensus Protocol**
- **Quorum Majority Voting**
- **Prepare & Accept Phases**
- **Conflict Resolution**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
