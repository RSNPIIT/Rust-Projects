# 🦀 Physical Unit Converter (`011_unit_converter`)

**Difficulty:** 🟢 Simple  
**Category:** Physics & Traits  

---

## 📖 Overview

Trait-based physical dimension unit converter for distance, mass, and volume conversions.

---

## 🎯 Key Rust Concepts Demonstrated

- **Trait Bounds**
- **Associated Types**
- **Unit Standardization**
- **Floating Point Conversions**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
