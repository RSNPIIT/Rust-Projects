# 🦀 ANSI Terminal Styler (`025_ansi_color_formatter`)

**Difficulty:** 🟢 Simple  
**Category:** CLI & Terminal  

---

## 📖 Overview

ANSI escape code wrapper providing colorful bold, underlined, and foreground/background styled terminal text.

---

## 🎯 Key Rust Concepts Demonstrated

- **ANSI Escape Sequences**
- **Method Chaining / Builder Pattern**
- **Display Trait**
- **Terminal UX**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
