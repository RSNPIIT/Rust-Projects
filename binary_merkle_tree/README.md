# 🦀 Cryptographic Binary Merkle Tree (`060_binary_merkle_tree`)

**Difficulty:** 🟡 Intermediate  
**Category:** Cryptography & Blockchain  

---

## 📖 Overview

Binary Merkle Tree generating root hashes and audit inclusion proofs for tamper-evident data verification.

---

## 🎯 Key Rust Concepts Demonstrated

- **Cryptographic Hash Trees**
- **Inclusion Proofs & Audit Paths**
- **Leaf Hashing**
- **Tamper Evident Verification**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
