# 🦀 Minimal JSON Field Extractor (`016_json_field_extractor`)

**Difficulty:** 🟢 Simple  
**Category:** Parsing & Text  

---

## 📖 Overview

Zero-dependency lightweight JSON string lexer and key-value extractor for flat objects.

---

## 🎯 Key Rust Concepts Demonstrated

- **Handwritten Lexer**
- **String Slicing & Parsing**
- **HashMap Key-Value Storage**
- **Safe Option Handling**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
