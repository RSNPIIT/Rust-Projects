# 🦀 Configurable Password Generator (`013_password_generator`)

**Difficulty:** 🟢 Simple  
**Category:** Security & Strings  

---

## 📖 Overview

Generates secure randomized passwords with configurable entropy, character set inclusions, and strength ratings.

---

## 🎯 Key Rust Concepts Demonstrated

- **Pseudo-Random Sampling**
- **Bitmasks & Config Enums**
- **Shannon Entropy Estimation**
- **String Generation**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
