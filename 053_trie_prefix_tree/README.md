# 🦀 Trie (Prefix Tree) Autocomplete (`053_trie_prefix_tree`)

**Difficulty:** 🟡 Intermediate  
**Category:** Data Structures & Strings  

---

## 📖 Overview

Trie prefix tree supporting word insertion, exact word search, prefix lookup, and auto-complete word suggestions.

---

## 🎯 Key Rust Concepts Demonstrated

- **Trie Node Hierarchy**
- **HashMap Children Branches**
- **Prefix Traversal & Backtracking**
- **String Autocomplete**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
