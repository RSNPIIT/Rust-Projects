# 🦀 Binary Search Tree (`020_binary_search_tree`)

**Difficulty:** 🟢 Simple  
**Category:** Trees & Algorithms  

---

## 📖 Overview

Recursive Binary Search Tree with node insertion, contains lookup, depth measurement, and in-order traversal.

---

## 🎯 Key Rust Concepts Demonstrated

- **Box<Option<Node>>**
- **Recursive Data Types**
- **In-Order Traversal**
- **Ord Trait Bounds**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
