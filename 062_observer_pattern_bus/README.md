# 🦀 Reactive Observer Event Bus (`062_observer_pattern_bus`)

**Difficulty:** 🟡 Intermediate  
**Category:** Design Patterns  

---

## 📖 Overview

Topic-based pub/sub notification message bus with subscribe tokens and unsubscribe unregistration.

---

## 🎯 Key Rust Concepts Demonstrated

- **Observer Pattern**
- **Subscription Handles**
- **Topic-Based Routing**
- **Dynamic Dispatch**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
