# 🦀 File Metadata Inspector (`012_file_metadata_inspector`)

**Difficulty:** 🟢 Simple  
**Category:** Filesystem & I/O  

---

## 📖 Overview

Inspects file size, permissions, file extension, and human-readable formatting of byte metrics.

---

## 🎯 Key Rust Concepts Demonstrated

- **std::fs & std::path**
- **PathBuf and Path**
- **Human Byte Formatting**
- **Error Handling**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
