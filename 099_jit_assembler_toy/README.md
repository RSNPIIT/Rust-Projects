# 🦀 Toy JIT Machine Code Assembler (`099_jit_assembler_toy`)

**Difficulty:** 🔴 Advanced  
**Category:** Low-Level & JIT Compilers  

---

## 📖 Overview

Encodes x86_64 machine opcodes (mov, add, ret) dynamically into executable memory format representation.

---

## 🎯 Key Rust Concepts Demonstrated

- **Machine Code Opcodes**
- **x86_64 Instruction Encoding**
- **Binary Assembler Emission**
- **JIT Compiler Foundations**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
