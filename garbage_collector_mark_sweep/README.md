# 🦀 Tracing Mark-and-Sweep Garbage Collector (`088_garbage_collector_mark_sweep`)

**Difficulty:** 🔴 Advanced  
**Category:** Memory Management & Compilers  

---

## 📖 Overview

Simulation of managed heap memory with root references, mark phase graph traversal, and sweep deallocation.

---

## 🎯 Key Rust Concepts Demonstrated

- **Tracing Garbage Collection**
- **Mark-and-Sweep Algorithm**
- **Object Graph Traversal**
- **Reclaiming Unreachable Heap**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
