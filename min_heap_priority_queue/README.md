# 🦀 Generic Binary Min-Heap (`059_min_heap_priority_queue`)

**Difficulty:** 🟡 Intermediate  
**Category:** Data Structures & Trees  

---

## 📖 Overview

Binary min-heap with sift-up and sift-down algorithms implementing O(log n) push/pop and O(n) heapify.

---

## 🎯 Key Rust Concepts Demonstrated

- **Array-Backed Complete Binary Tree**
- **Sift-Up / Sift-Down**
- **Min-Heap Invariant**
- **Generic Ordering `T: Ord`**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
