# 🦀 Sliding Window Percentile Metrics (`097_sliding_window_metrics`)

**Difficulty:** 🔴 Advanced  
**Category:** Observability & Metrics  

---

## 📖 Overview

High-throughput sliding time window recording latencies and computing p50, p90, and p99 quantiles.

---

## 🎯 Key Rust Concepts Demonstrated

- **Rolling Time Windows**
- **Quantile / Percentile Approximation**
- **Monotonic Time Ordering**
- **High-Throughput Metrics**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
