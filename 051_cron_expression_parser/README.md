# 🦀 Cron Expression Parser (`051_cron_expression_parser`)

**Difficulty:** 🟡 Intermediate  
**Category:** Time & Scheduling  

---

## 📖 Overview

5-field cron parser supporting wildcards, exact values, lists, and intervals for minute/hour/dom/month/dow scheduling.

---

## 🎯 Key Rust Concepts Demonstrated

- **Domain-Specific Language (DSL) Parsing**
- **Range & Step Matching**
- **Bitmasks for Match Sets**
- **Time Field Validation**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
