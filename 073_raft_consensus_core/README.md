# 🦀 Raft Consensus Core State Machine (`073_raft_consensus_core`)

**Difficulty:** 🔴 Advanced  
**Category:** Distributed Systems & Consensus  

---

## 📖 Overview

Core Raft protocol state machine modeling Follower, Candidate, and Leader roles, terms, voting, and heartbeats.

---

## 🎯 Key Rust Concepts Demonstrated

- **Raft Consensus Algorithm**
- **Leader Election & Terms**
- **Heartbeat & Election Timers**
- **State Machine Transitions**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
