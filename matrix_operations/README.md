# 🦀 2D Matrix Operations (`010_matrix_operations`)

**Difficulty:** 🟢 Simple  
**Category:** Linear Algebra  

---

## 📖 Overview

Matrix data structure with addition, subtraction, scalar scaling, transposition, and dot-product multiplication.

---

## 🎯 Key Rust Concepts Demonstrated

- **2D Vectors**
- **Operator Overloading**
- **Dimension Validation**
- **Linear Algebra**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
