# 🦀 Mini Actor Model Concurrency System (`072_mini_actor_system`)

**Difficulty:** 🔴 Advanced  
**Category:** Concurrency & Distributed Systems  

---

## 📖 Overview

Erlang/Akka-inspired Actor system with isolated actor mailboxes, asynchronous message passing, and state encapsulation.

---

## 🎯 Key Rust Concepts Demonstrated

- **Actor Model Pattern**
- **Mailbox Queues with Channels**
- **Thread Concurrency**
- **Actor Context & Addressing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
