# 🦀 Multi-Layer Perceptron (MLP) Neural Net (`082_neural_network_mlp`)

**Difficulty:** 🔴 Advanced  
**Category:** AI & Machine Learning  

---

## 📖 Overview

2-layer neural network with forward pass activation (Sigmoid) and error backpropagation training for XOR logic.

---

## 🎯 Key Rust Concepts Demonstrated

- **Matrix Forward Pass**
- **Sigmoid Activation Function**
- **Backpropagation Calculus**
- **Gradient Descent Updates**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
