# 🦀 Probabilistic Skip List (`063_skiplist`)

**Difficulty:** 🟡 Intermediate  
**Category:** Data Structures & Search  

---

## 📖 Overview

Multi-level probabilistic skip list achieving expected O(log n) search, insertion, and ordered traversal.

---

## 🎯 Key Rust Concepts Demonstrated

- **Skip List Multi-Level Pointers**
- **Probabilistic Coin Toss Height**
- **O(log n) Expected Time**
- **Ordered Iteration**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
