# 🦀 Concurrent Stream Pipeline (`054_concurrency_pipeline`)

**Difficulty:** 🟡 Intermediate  
**Category:** Concurrency & Channels  

---

## 📖 Overview

Multi-stage stream processing pipeline communicating across concurrent stages using bounded mpsc channels.

---

## 🎯 Key Rust Concepts Demonstrated

- **Pipeline Architecture**
- **Producer-Consumer Pattern**
- **Channel Backpressure**
- **Thread Pipelining**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
