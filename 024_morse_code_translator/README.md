# 🦀 Morse Code Translator (`024_morse_code_translator`)

**Difficulty:** 🟢 Simple  
**Category:** Strings & Encodings  

---

## 📖 Overview

Bi-directional translator between text and International Morse Code with word-delimiter slash formatting.

---

## 🎯 Key Rust Concepts Demonstrated

- **Lookup Table Mapping**
- **Splitting & Joining**
- **Bidirectional Dictionaries**
- **Char Mapping**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
