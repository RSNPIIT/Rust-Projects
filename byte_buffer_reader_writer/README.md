# 🦀 Endian & Varint Binary Codec (`069_byte_buffer_reader_writer`)

**Difficulty:** 🟡 Intermediate  
**Category:** Serialization & Binary  

---

## 📖 Overview

Binary buffer reader/writer supporting Little-Endian, Big-Endian primitives, and Google Protocol Buffer Varint encoding.

---

## 🎯 Key Rust Concepts Demonstrated

- **LE/BE Byte Ordering**
- **Protobuf Varint LEB128 Encoding**
- **Cursor Tracking**
- **Binary Serialization**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
