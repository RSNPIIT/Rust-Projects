# 🦀 SIMD Vectorized Linear Algebra (`089_simd_vector_math`)

**Difficulty:** 🔴 Advanced  
**Category:** High Performance & SIMD  

---

## 📖 Overview

High-throughput 4-lane SIMD vector operations (dot product, cross product, normalization) with fallback scalar paths.

---

## 🎯 Key Rust Concepts Demonstrated

- **4-Lane Vector SIMD Emulation**
- **Dot & Cross Products**
- **Vector Normalization**
- **Fast Inverse Square Root**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
