# 🦀 Classic Sorting Suite (`022_sorting_algorithms`)

**Difficulty:** 🟢 Simple  
**Category:** Algorithms  

---

## 📖 Overview

Collection of standard sorting algorithms: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort.

---

## 🎯 Key Rust Concepts Demonstrated

- **In-Place Mutation**
- **Divide and Conquer**
- **Generic Slices `&mut [T]`**
- **Ord Bounds**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
