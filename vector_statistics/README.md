# 🦀 Vector Statistical Calculator (`023_vector_statistics`)

**Difficulty:** 🟢 Simple  
**Category:** Math & Statistics  

---

## 📖 Overview

Calculates descriptive statistics: mean, median, mode, sample variance, standard deviation, and range.

---

## 🎯 Key Rust Concepts Demonstrated

- **Statistical Aggregations**
- **Sorting & Quantiles**
- **HashMap Mode Tally**
- **Float Casts**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
