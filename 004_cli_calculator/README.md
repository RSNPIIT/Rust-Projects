# 🦀 CLI Calculator (`004_cli_calculator`)

**Difficulty:** 🟢 Simple  
**Category:** Parsing & Math  

---

## 📖 Overview

Arithmetic calculator supporting +, -, *, /, parenthesis, and operator precedence using the Shunting-Yard algorithm.

---

## 🎯 Key Rust Concepts Demonstrated

- **Lexing / Tokenization**
- **Shunting-Yard Algorithm**
- **Reverse Polish Notation (RPN)**
- **Error Handling (Result/Option)**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
