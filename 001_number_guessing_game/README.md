# 🦀 Number Guessing Game (`001_number_guessing_game`)

**Difficulty:** 🟢 Simple  
**Category:** CLI & Game Logic  

---

## 📖 Overview

Interactive number guessing game with binary search hint system, input validation, and attempts tracking.

---

## 🎯 Key Rust Concepts Demonstrated

- **Standard I/O**
- **Looping & Pattern Matching**
- **Parsing Strings to Numbers**
- **Pseudo-Random Number Generation (LCG)**
- **Unit Testing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
