# 🦀 Generic Stack & Queue (`014_stack_and_queue`)

**Difficulty:** 🟢 Simple  
**Category:** Data Structures  

---

## 📖 Overview

Generic implementations of LIFO Stack and FIFO Queue with peak, size, capacity, and iterator capabilities.

---

## 🎯 Key Rust Concepts Demonstrated

- **Generics `<T>`**
- **LIFO vs FIFO Semantics**
- **VecDeque & Vec Backings**
- **Unit Testing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
