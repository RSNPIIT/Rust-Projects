# 🦀 Temperature Converter (`002_temperature_converter`)

**Difficulty:** 🟢 Simple  
**Category:** Math & Enums  

---

## 📖 Overview

Multi-scale temperature converter supporting Celsius, Fahrenheit, and Kelvin with custom enum traits and precision rounding.

---

## 🎯 Key Rust Concepts Demonstrated

- **Enums with Methods**
- **Traits (Display, From)**
- **Floating Point Precision**
- **Exhaustive Pattern Matching**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
