# 🦀 Rock-Paper-Scissors Simulator (`019_rock_paper_scissors`)

**Difficulty:** 🟢 Simple  
**Category:** Games & Enums  

---

## 📖 Overview

Rock, Paper, Scissors, Lizard, Spock game logic with round scoring and strategy evaluation.

---

## 🎯 Key Rust Concepts Demonstrated

- **Enums with Comparisons**
- **Match Expressions**
- **Round Accounting**
- **Custom Display**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
