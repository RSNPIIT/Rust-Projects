# 🦀 CLI Animated Progress Bar (`035_cli_progress_bar`)

**Difficulty:** 🟢 Simple  
**Category:** CLI & Animation  

---

## 📖 Overview

Terminal progress bar with percentage counter, spinner glyphs, and carriage return `\r` line rewriting.

---

## 🎯 Key Rust Concepts Demonstrated

- **Carriage Return `\r`**
- **Standard Output Flushing (`io::stdout().flush()`)**
- **Time Estimation**
- **Formatted Strings**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
