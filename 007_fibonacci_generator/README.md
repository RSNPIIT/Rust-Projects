# 🦀 Fibonacci Generator (`007_fibonacci_generator`)

**Difficulty:** 🟢 Simple  
**Category:** Math & Iterators  

---

## 📖 Overview

Generates Fibonacci sequences via iterative, memoized, recursive, and custom infinite `Iterator` trait approaches.

---

## 🎯 Key Rust Concepts Demonstrated

- **Iterator Trait Implementation**
- **Memoization with HashMap**
- **Stack vs Heap Recursion**
- **Infinite Streams (take)**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
