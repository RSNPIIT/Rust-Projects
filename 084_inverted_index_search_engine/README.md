# 🦀 Inverted Index Full-Text Search Engine (`084_inverted_index_search_engine`)

**Difficulty:** 🔴 Advanced  
**Category:** Search & Information Retrieval  

---

## 📖 Overview

Full-text search engine with term-document inverted posting lists, boolean AND/OR queries, and TF-IDF scoring.

---

## 🎯 Key Rust Concepts Demonstrated

- **Inverted Index Posting Lists**
- **Term Frequency (TF)**
- **Boolean Set Intersections**
- **Relevance Scoring**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
