# 🦀 Thompson's NFA Regex Engine (`045_mini_regex_engine`)

**Difficulty:** 🟡 Intermediate  
**Category:** Compilers & Automata  

---

## 📖 Overview

Non-deterministic Finite Automaton (NFA) regex engine supporting characters, wildcard `.`, and `*` repetition.

---

## 🎯 Key Rust Concepts Demonstrated

- **Automata Theory**
- **Thompson's Construction**
- **State Transitions**
- **Recursive Pattern Matching**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
