# 🦀 Stack-Based Bytecode Virtual Machine (`071_bytecode_virtual_machine`)

**Difficulty:** 🔴 Advanced  
**Category:** Virtual Machines & Compilers  

---

## 📖 Overview

Full stack VM with instruction pointer, call frames, arithmetic, comparison, jumps, and bytecode execution loop.

---

## 🎯 Key Rust Concepts Demonstrated

- **Virtual Machine Architecture**
- **Stack Evaluation Loop**
- **Opcode Dispatcher**
- **Instruction Pointer Manipulation**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
