# 🦀 Dotenv (.env) File Parser (`027_env_var_loader`)

**Difficulty:** 🟢 Simple  
**Category:** Parsing & Config  

---

## 📖 Overview

Custom environment file reader parsing key-value pairs, ignoring comments, and stripping quotes.

---

## 🎯 Key Rust Concepts Demonstrated

- **File Line Parsing**
- **String Trimming**
- **HashMap Indexing**
- **Key-Value Extraction**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
