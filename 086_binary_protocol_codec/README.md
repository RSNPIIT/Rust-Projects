# 🦀 High-Performance TLV Binary Codec (`086_binary_protocol_codec`)

**Difficulty:** 🔴 Advanced  
**Category:** Protocols & Networking  

---

## 📖 Overview

Type-Length-Value (TLV) framing codec with packet magic, checksum calculation, and binary payload decoding.

---

## 🎯 Key Rust Concepts Demonstrated

- **Type-Length-Value (TLV) Protocol**
- **Packet Framing & Framing Errors**
- **Integrity Checksums**
- **Wire Format Encoding**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
