# 🦀 Dijkstra's Shortest Path Algorithm (`044_dijkstra_pathfinding`)

**Difficulty:** 🟡 Intermediate  
**Category:** Graphs & Algorithms  

---

## 📖 Overview

Weighted graph shortest-path engine with BinaryHeap min-priority queue and path backtracking.

---

## 🎯 Key Rust Concepts Demonstrated

- **Graph Adjacency Lists**
- **BinaryHeap Priority Queue**
- **Reverse Ordering**
- **Shortest Path Reconstruction**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
