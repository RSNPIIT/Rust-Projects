# 🦀 Myers Line Diff Engine (`050_diff_tool`)

**Difficulty:** 🟡 Intermediate  
**Category:** Algorithms & Text  

---

## 📖 Overview

Line-by-line file difference generator calculating added, deleted, and identical lines using Myers diff.

---

## 🎯 Key Rust Concepts Demonstrated

- **Diff Algorithms**
- **Unified Diff Formatting**
- **Dynamic Grid Traversal**
- **Edit Script Construction**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
