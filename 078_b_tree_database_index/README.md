**Difficulty:** 🔴 Advanced  
**Category:** Databases & Trees

## 📖 Overview

Multi-way balanced B+ Tree search index with node splitting, key search, and range traversal.

---

## 🎯 Key Rust Concepts Demonstrated

- **B+ Tree Invariant**
- **Node Splitting Logic**
- **Balanced Search Trees**
- **Database Index Architecture**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
