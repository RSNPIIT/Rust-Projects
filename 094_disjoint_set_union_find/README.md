# 🦀 Disjoint-Set (Union-Find) with Path Compression (`094_disjoint_set_union_find`)

**Difficulty:** 🔴 Advanced  
**Category:** Algorithms & Graphs  

---

## 📖 Overview

Disjoint-Set Union (DSU) data structure with path compression and union by rank for Kruskal's Minimum Spanning Tree.

---

## 🎯 Key Rust Concepts Demonstrated

- **Disjoint Set Union**
- **Path Compression**
- **Union by Rank**
- **Cycle Detection in Graphs**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
