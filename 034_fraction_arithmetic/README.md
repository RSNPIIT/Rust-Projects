# 🦀 Exact Rational Fraction Arithmetic (`034_fraction_arithmetic`)

**Difficulty:** 🟢 Simple  
**Category:** Math & Operator Overloading  

---

## 📖 Overview

Exact rational number implementation supporting +, -, *, / operator overloading with greatest common divisor (GCD) reduction.

---

## 🎯 Key Rust Concepts Demonstrated

- **Operator Overloading (std::ops)**
- **Euclidean GCD Algorithm**
- **Exact Rational Numbers**
- **Custom Display**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
