# 🦀 Semantic Versioning (SemVer 2.0.0) Parser (`066_semver_parser`)

**Difficulty:** 🟡 Intermediate  
**Category:** Parsing & Comparison  

---

## 📖 Overview

Full SemVer 2.0.0 parser with Major, Minor, Patch, pre-release tags, build metadata, and ordering precedence.

---

## 🎯 Key Rust Concepts Demonstrated

- **Semantic Versioning 2.0.0**
- **Custom Ord / PartialOrd**
- **Pre-Release Precedence Rules**
- **String Slicing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
