# 🦀 To-Do List CLI Manager (`005_todo_cli`)

**Difficulty:** 🟢 Simple  
**Category:** Data Management & CRUD  

---

## 📖 Overview

In-memory task organizer with priority levels, status transitions, formatted listing, and filtering.

---

## 🎯 Key Rust Concepts Demonstrated

- **Structs & Enums**
- **CRUD State Operations**
- **Display Trait Custom Formatting**
- **Vector Mutability**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
