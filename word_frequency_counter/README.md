# 🦀 Word Frequency Counter (`003_word_frequency_counter`)

**Difficulty:** 🟢 Simple  
**Category:** Text & Collections  

---

## 📖 Overview

Tokenizes text, strips punctuation, normalizes case, and counts word occurrences using HashMap and sorting.

---

## 🎯 Key Rust Concepts Demonstrated

- **HashMap Entry API**
- **Iterators & Closures**
- **String Normalization**
- **Custom Sorting (Ord / PartialOrd)**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
