# 🦀 Distributed Gossip-Protocol Cluster (`100_distributed_key_value_cluster`)

**Difficulty:** 🔴 Advanced  
**Category:** Distributed Systems  

---

## 📖 Overview

Decentralized cluster communicating state via gossip anti-entropy protocol with heartbeat health detection.

---

## 🎯 Key Rust Concepts Demonstrated

- **Gossip / Epidemic Protocols**
- **Anti-Entropy State Merging**
- **Cluster Membership & Heartbeats**
- **Decentralized Key-Value Storage**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
