# 🦀 Consistent Hashing Ring (`052_consistent_hashing`)

**Difficulty:** 🟡 Intermediate  
**Category:** Distributed Systems  

---

## 📖 Overview

Consistent hash ring with virtual nodes distributing keys evenly across dynamically joining/leaving server nodes.

---

## 🎯 Key Rust Concepts Demonstrated

- **Consistent Hash Ring**
- **Virtual Node Replication**
- **Binary Search (BTreeMap/partition_point)**
- **Distributed Caching**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
