# 🦀 CRC-32 Checksum Digest (`029_hash_digest_crc32`)

**Difficulty:** 🟢 Simple  
**Category:** Hashing & Cryptography  

---

## 📖 Overview

Standard IEEE 802.3 CRC-32 checksum calculator with precomputed lookup table acceleration.

---

## 🎯 Key Rust Concepts Demonstrated

- **Lookup Table Precomputation**
- **Bitwise XOR and Shift Operations**
- **Polynomial Hashing**
- **Checksum Verification**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
