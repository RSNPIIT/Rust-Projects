# 🦀 Chandy-Lamport Distributed Snapshot (`098_chandy_lamport_snapshot`)

**Difficulty:** 🔴 Advanced  
**Category:** Distributed Systems  

---

## 📖 Overview

Chandy-Lamport algorithm capturing a consistent global state across concurrent communicating processes without stopping the system.

---

## 🎯 Key Rust Concepts Demonstrated

- **Chandy-Lamport Snapshot**
- **Marker Message Transmission**
- **In-Flight Channel State**
- **Consistent Global Cut**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
