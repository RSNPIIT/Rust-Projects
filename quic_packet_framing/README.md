# 🦀 QUIC Variable-Length Integer & Packet Framing (`090_quic_packet_framing`)

**Difficulty:** 🔴 Advanced  
**Category:** Networking & Protocols  

---

## 📖 Overview

RFC 9000 QUIC variable-length integer encoding (1, 2, 4, 8 bytes) and Initial packet header framing.

---

## 🎯 Key Rust Concepts Demonstrated

- **RFC 9000 QUIC Protocol**
- **Variable-Length Integer Encoding**
- **Long Header Format**
- **Binary Wire Framing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
