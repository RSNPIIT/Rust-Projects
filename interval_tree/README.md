# 🦀 Augmented Interval Tree (`070_interval_tree`)

**Difficulty:** 🟡 Intermediate  
**Category:** Trees & Computational Geometry  

---

## 📖 Overview

Augmented Binary Search Tree storing numeric intervals with subtree max-endpoint caching for O(log n) overlap searches.

---

## 🎯 Key Rust Concepts Demonstrated

- **Augmented Trees**
- **Interval Overlap Detection**
- **Recursive Subtree Bounds**
- **Computational Geometry**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
