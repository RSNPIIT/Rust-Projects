# 🦀 Probabilistic Bloom Filter (`032_bloom_filter_simple`)

**Difficulty:** 🟢 Simple  
**Category:** Probabilistic Data Structures  

---

## 📖 Overview

Space-efficient probabilistic filter testing set membership with zero false negatives and tunable false positives.

---

## 🎯 Key Rust Concepts Demonstrated

- **Bit Vectors (`Vec<bool>`)**
- **Multiple Independent Hashes**
- **Probabilistic Guarantees**
- **False Positive Math**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
