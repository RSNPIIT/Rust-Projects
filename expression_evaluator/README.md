# 🦀 Abstract Syntax Tree (AST) Evaluator (`040_expression_evaluator`)

**Difficulty:** 🟡 Intermediate  
**Category:** Compilers & Interpreters  

---

## 📖 Overview

Recursive descent math expression parser producing an Abstract Syntax Tree (AST) with variable environments.

---

## 🎯 Key Rust Concepts Demonstrated

- **Recursive Descent Parsing**
- **AST Enum Trees**
- **Variable Scoping / Environment**
- **Tree Walk Evaluation**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
