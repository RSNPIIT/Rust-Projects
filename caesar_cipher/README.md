# 🦀 Caesar Cipher Tool (`009_caesar_cipher`)

**Difficulty:** 🟢 Simple  
**Category:** Cryptography & Strings  

---

## 📖 Overview

Symmetric shift cipher encryptor and decryptor supporting arbitrary positive and negative key shifts.

---

## 🎯 Key Rust Concepts Demonstrated

- **Char Manipulation & Casting**
- **Modulo Arithmetic**
- **Symmetric Ciphers**
- **Boundary Handling**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
