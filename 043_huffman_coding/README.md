# 🦀 Huffman Coding & Compression (`043_huffman_coding`)

**Difficulty:** 🟡 Intermediate  
**Category:** Algorithms & Compression  

---

## 📖 Overview

Prefix-free variable-length binary encoding with Huffman tree generation, prefix tables, and lossless decode.

---

## 🎯 Key Rust Concepts Demonstrated

- **Binary Trees**
- **Priority Queues (BinaryHeap)**
- **Prefix Codes**
- **Lossless Data Compression**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
