# 🦀 Vector Similarity Search Engine (`076_vector_similarity_search`)

**Difficulty:** 🔴 Advanced  
**Category:** AI & Vector Databases  

---

## 📖 Overview

High-dimensional embedding index calculating Cosine Similarity and Euclidean distance for k-Nearest Neighbors (KNN).

---

## 🎯 Key Rust Concepts Demonstrated

- **High-Dimensional Vector Math**
- **Cosine Similarity Formula**
- **Euclidean Metric Distance**
- **KNN Top-K Ranking**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
