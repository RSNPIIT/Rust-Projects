# 🦀 Compiler Lexer, Parser & AST Builder (`080_compiler_lexer_parser`)

**Difficulty:** 🔴 Advanced  
**Category:** Compilers & Languages  

---

## 📖 Overview

Lexical scanner and recursive descent parser transforming code strings into an Abstract Syntax Tree (AST).

---

## 🎯 Key Rust Concepts Demonstrated

- **Compiler Front-End Pipeline**
- **Token Stream Lexing**
- **Recursive Descent Grammar**
- **Typed AST Hierarchy**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
