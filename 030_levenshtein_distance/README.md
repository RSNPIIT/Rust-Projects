# 🦀 Levenshtein Distance & Fuzzy Matcher (`030_levenshtein_distance`)

**Difficulty:** 🟢 Simple  
**Category:** Dynamic Programming & NLP  

---

## 📖 Overview

Calculates minimum single-character edit distance (insertions, deletions, substitutions) between strings.

---

## 🎯 Key Rust Concepts Demonstrated

- **Dynamic Programming Matrix**
- **Fuzzy Search Ranking**
- **Unicode Grapheme Handling**
- **Matrix Memoization**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
