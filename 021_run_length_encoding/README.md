# 🦀 Run-Length Encoding (RLE) (`021_run_length_encoding`)

**Difficulty:** 🟢 Simple  
**Category:** Compression & Strings  

---

## 📖 Overview

Lossless data compression algorithm encoding repeated consecutive values into (count, char) tokens.

---

## 🎯 Key Rust Concepts Demonstrated

- **Char Peakable Iteration**
- **Compression Ratio Metric**
- **String Reassembly**
- **Lossless Roundtrips**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
