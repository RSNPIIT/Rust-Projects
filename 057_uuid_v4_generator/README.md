# 🦀 RFC 4122 UUID v4 Generator (`057_uuid_v4_generator`)

**Difficulty:** 🟡 Intermediate  
**Category:** Cryptography & IDs  

---

## 📖 Overview

Standard 128-bit Universally Unique Identifier v4 generator setting version (4) and variant (RFC 4122) bits.

---

## 🎯 Key Rust Concepts Demonstrated

- **RFC 4122 Standard**
- **Bit Masking & Version Setting**
- **Hexadecimal Encoding**
- **UUID Canonical Formatting**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
