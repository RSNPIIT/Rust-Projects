# 🦀 Precision Stopwatch & Lap Timer (`028_stopwatch_timer`)

**Difficulty:** 🟢 Simple  
**Category:** Time & Benchmarking  

---

## 📖 Overview

High-precision timer supporting start, pause, resume, and split lap timing using std::time::Instant.

---

## 🎯 Key Rust Concepts Demonstrated

- **std::time::Instant**
- **std::time::Duration**
- **State Transitions**
- **Microsecond Precision**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
