# 🦀 Luhn Algorithm Credit Card Validator (`018_luhn_algorithm`)

**Difficulty:** 🟢 Simple  
**Category:** Algorithms & Validation  

---

## 📖 Overview

Calculates and verifies checksum digits according to the Luhn (Mod 10) formula used in payment cards.

---

## 🎯 Key Rust Concepts Demonstrated

- **Iterator Reversal**
- **Char Digit Extraction**
- **Checksum Calculation**
- **Unit Testing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
