# 🦀 Palindrome Checker (`006_palindrome_checker`)

**Difficulty:** 🟢 Simple  
**Category:** Strings & Algorithms  

---

## 📖 Overview

Unicode and whitespace-agnostic palindrome validator with bidirectional iterator comparison.

---

## 🎯 Key Rust Concepts Demonstrated

- **String Iterators**
- **Double-Ended Iterators**
- **Unicode Char Filtering**
- **Complexity Analysis**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
