# 🦀 URL Slug Generator & Sanitizer (`033_slug_generator`)

**Difficulty:** 🟢 Simple  
**Category:** Strings & Web  

---

## 📖 Overview

Transforms arbitrary article headlines and product names into URL-friendly kebab-case slugs.

---

## 🎯 Key Rust Concepts Demonstrated

- **Char Classification**
- **Kebab-Case Formatting**
- **Consecutive Hyphen Collapsing**
- **Unicode ASCII Transliteration**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
