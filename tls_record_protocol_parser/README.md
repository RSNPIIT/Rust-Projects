# 🦀 TLS 1.3 ClientHello Record Parser (`096_tls_record_protocol_parser`)

**Difficulty:** 🔴 Advanced  
**Category:** Cryptography & Security  

---

## 📖 Overview

Wire decoder for TLS 1.3 records, handshake frames, ClientHello random bytes, session ID, and cipher suites.

---

## 🎯 Key Rust Concepts Demonstrated

- **TLS Record Layer**
- **ClientHello Handshake Framing**
- **Cipher Suite Enumeration**
- **Binary Protocol Decoding**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
