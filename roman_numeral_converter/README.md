# 🦀 Roman Numeral Converter (`015_roman_numeral_converter`)

**Difficulty:** 🟢 Simple  
**Category:** Math & Strings  

---

## 📖 Overview

Bi-directional converter between standard integers (1-3999) and Roman numerals with subtractive notation.

---

## 🎯 Key Rust Concepts Demonstrated

- **Pattern Matching**
- **Greedy Subtraction**
- **String Accumulation**
- **Validation & Parsing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
