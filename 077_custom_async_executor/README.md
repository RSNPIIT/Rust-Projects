# 🦀 Custom Cooperative Async Executor (`077_custom_async_executor`)

**Difficulty:** 🔴 Advanced  
**Category:** Async & Systems  

---

## 📖 Overview

Toy cooperative task scheduler simulating Rust's Future polling, Ready/Pending states, and task wakeups.

---

## 🎯 Key Rust Concepts Demonstrated

- **Cooperative Multitasking**
- **Future Polling Semantics**
- **Task State Machine**
- **Waker & Scheduler Loops**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
