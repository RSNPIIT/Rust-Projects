# 🦀 Markdown to HTML Transpiler (`048_markdown_to_html`)

**Difficulty:** 🟡 Intermediate  
**Category:** Compilers & Text  

---

## 📖 Overview

Parses common Markdown syntax: headings (#), bold (**), italics (*), code blocks, and links into valid HTML.

---

## 🎯 Key Rust Concepts Demonstrated

- **Lexical Analysis**
- **Inline Markup Transformation**
- **HTML Sanitization**
- **Line-by-line Parsing**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
