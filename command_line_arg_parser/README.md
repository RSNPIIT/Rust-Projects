# 🦀 CLI Argument Parser from Scratch (`067_command_line_arg_parser`)

**Difficulty:** 🟡 Intermediate  
**Category:** CLI & Parsing  

---

## 📖 Overview

Zero-dependency CLI argument parser supporting boolean flags (-v), key-value options (--port=8080), and positional args.

---

## 🎯 Key Rust Concepts Demonstrated

- **Iterator Traversal**
- **Short Flags & Long Options**
- **Positional Arguments**
- **Help Text Auto-Generation**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
