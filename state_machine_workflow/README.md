# 🦀 Type-State Workflow State Machine (`061_state_machine_workflow`)

**Difficulty:** 🟡 Intermediate  
**Category:** Design Patterns & Types  

---

## 📖 Overview

Compile-time verified finite state machine preventing invalid transitions using Rust's zero-cost typestate pattern.

---

## 🎯 Key Rust Concepts Demonstrated

- **Type-State Pattern**
- **Zero-Cost PhantomData Encodings**
- **Compile-Time State Verification**
- **Consuming Self Transitions**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
