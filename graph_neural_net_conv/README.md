# 🦀 Graph Convolutional Network (GCN) Layer (`095_graph_neural_net_conv`)

**Difficulty:** 🔴 Advanced  
**Category:** AI & Graph Neural Networks  

---

## 📖 Overview

Graph Convolutional Network layer aggregating neighbor node features via normalized adjacency matrix multiplication.

---

## 🎯 Key Rust Concepts Demonstrated

- **Graph Convolutions**
- **Neighbor Message Aggregation**
- **Adjacency Normalization**
- **Feature Projection**

---

## 🚀 How to Run

Navigate into this project directory and use `cargo`:

```bash
# Run the project
cargo run

# Run with quiet cargo output
cargo run -q

# Run unit tests
cargo test
```
